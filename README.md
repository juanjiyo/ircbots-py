# IRC Bots

A collection of IRC bots built with modern JavaScript/TypeScript.

## Features

- Modular bot architecture
- Easy to extend with new commands
- Configurable settings
- Multiple bot support

## Installation

```bash
npm install
```

## Usage

```bash
npm run dev
```

## Development

```bash
# Run linter
npm run lint

# Run tests
npm test

# Build for production
npm run build
```
