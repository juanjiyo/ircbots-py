# Módulo de Juegos Sociales de MiLeNiUm

Esta carpeta contiene los minijuegos y utilidades de entretenimiento del bot **MiLeNiUm**, orientados principalmente a la interacción social en el canal.

## Estructura de Directorios

- `core/`: Contiene la lógica compartida (timers, funciones auxiliares).
- `datos/`: Almacenamiento JSON/SQLite para mantener el estado (parejas, estadísticas).
- `amorometro/`: Módulo para medir la compatibilidad entre dos usuarios en el canal.
- `matrimonio/`: Módulo para gestionar el sistema de bodas virtuales, incluyendo propuestas, aceptaciones, rechazos y divorcios.

Juegos activos: ahorcado, amorometro, castillo, dados, dragones, hechicero, matrimonio, ruleta, trileros, y todos los de core/ (economía, frases, social, quotes, etc.).
